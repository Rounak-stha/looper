# Changelog

All notable changes to this project will be documented here.

## [0.1.0-alpha] - 2026-09-21

### Added

- Provider-neutral contracts for decisions, reasoning, routing, context, workspaces, tools, snapshots, and authoritative evaluation.
- Deterministic experiment scheduling, manifests, JSONL evidence, usage accounting, reporting, replay, and paired comparisons.
- Bounded coding-agent loop with closed file/search/test tools and separate visible versus authoritative outcomes.
- Optional TypeSafe System One, OpenAI, Azure OpenAI, OpenAI-compatible, Docker/Git, BugsInPy, and SWE-bench adapters.
- Zero-credential local end-to-end smoke.
- Multi-repository BugsInPy selection, robustness, 180-run development, and six-task held-out pilot reports.

### Security and reproducibility

- Environment-only credentials and rejection of inline API keys.
- Sanitized candidate summaries, bounded context, opaque identifiers, transactional artifacts, and retained failure usage.
- Digest-pinned Docker execution, including exact local image-ID recovery when a repository-digest alias is unavailable.

### Status

Experimental alpha. The current evidence is small and mixed; it does not establish benchmark superiority, statistical significance, production readiness, or broad generalization.
